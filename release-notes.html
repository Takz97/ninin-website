Release

ninin 1.0

The first Windows desktop release of ninin.

What's included

  • Author's Desk project management
  • Manuscript and scene writing
  • Worldbuilding and continuity tools
  • Backup and recovery safeguards
  • EPUB and DOCX export workflows
  • Windows desktop app with a bundled local service

Release status

ninin 1.0 has been manually tested through the core writing workflow and packaged installation process. The release is prepared for Windows distribution, with code signing and final publication steps remaining before public release.
